# 🛍️ Product Search System with AI Chatbot & Personalized Recommendations

A full-stack e-commerce product search application that enables intelligent product discovery using **Typesense**, enhanced with an **AI-powered chatbot** and a **personalized recommendation system**.

## Features

* Fast product search with Typesense
* AI-powered shopping chatbot
* Personalized product recommendations
* Search suggestions and autocomplete
* Product filtering and pagination
* Product details view
* Responsive user interface

## Tech Stack

**Frontend**

* React
* Vite
* JavaScript
* CSS

**Backend**

* Node.js
* Express.js

**Search Engine**

* Typesense

**Data Processing**

* Python
* Amazon Product Dataset
